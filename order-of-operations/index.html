أولويات العمليات الحسابية

تطبيق تفاعلي بمسائل حياتية متدرجة: سهل ثم متوسط ثم صعب (مع أقواس وأسُس وعمليات متنوعة).

سُلّم القوة (من الأقوى إلى الأضعف)

  1. الأقواس ( ) ثم [ ] ثم { } وأي تجميع مثل خط الكسر.
  2. الأسس والجذور (مثل 9² أو √49).
  3. الضرب والقسمة (بنفس القوة) — نتحرك حسب ترتيب الظهور (يسار → يمين).
  4. الجمع والطرح (بنفس القوة) — نتحرك حسب ترتيب الظهور (يسار → يمين).
تذكير: الهدف ليس “حفظ ترتيب” فقط—بل فهم المعنى: الأقواس = حزمة، الأس = قوة/تكرار، الضرب = لكل/معدل، القسمة = توزيع.
نصيحة: اكتب التعبير أولًا (من القصة)، ثم طبّق سُلّم القوة خطوة خطوة.
