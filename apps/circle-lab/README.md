# رحلة اكتشاف الدائرة: من موجات الماء إلى الفرجار

تم تعديل المشروع ليبدأ بمرحلة تمهيدية جديدة قبل المستوى الأول:

1. موقف حياتي متحرك: حجر يسقط في بركة ماء، وتظهر موجات دائرية متتالية حول مكان سقوط الحجر.
2. استنتاج المفهوم: يظهر المركز ونصف القطر بالتدريج، ثم تظهر خلاصة تعريف الدائرة.

## الملفات المعدلة

- `index.html`: إضافة تبويب التمهيد وقسم موجات الماء واستنتاج المفهوم.
- `css/style.css`: إضافة تنسيقات شاشة التمهيد والبطاقات والأسئلة الموجهة.
- `js/script.js`: إضافة رسم الأنيميشن على Canvas، ونظام فتح المستوى الأول بعد إنهاء التمهيد، وتسجيل حدث التمهيد ضمن بيانات الطالب.

## طريقة الاستخدام

انسخ محتويات هذا المجلد فوق مشروعك الحالي مع الحفاظ على البنية:

- `index.html`
- `matching-game.html`
- `css/style.css`
- `css/matching-game.css`
- `js/script.js`
- `js/data-matching-game.js`
- `js/matching-game.js`
