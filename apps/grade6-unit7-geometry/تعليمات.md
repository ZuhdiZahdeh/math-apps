# نشر حقيبة المعلم - الصف السادس - الوحدة السابعة: الهندسة

## ما الجديد في هذه النسخة؟

تم تعديل الصفحة الرئيسية للحقيبة بحيث تفتح ملفات PDF داخل الصفحة نفسها من خلال قسم جديد باسم:

`عارض ملفات PDF داخل الصفحة`

ويحتوي العارض على:

- الخطة الفصلية.
- خطة الوحدة.
- تحاضير الدروس 1-7.
- زر فتح في تبويب جديد لكل ملف.
- زر تحميل لكل ملف.
- زر نسخ الرابط.

> ملاحظة مهمة: إذا فتحت ملف `index.html` وحده في المعاينة ولم تكن مجلدات `plans` و `preparations` بجانبه، فلن تظهر ملفات PDF. يجب رفع الحزمة كاملة إلى GitHub أو فتحها من داخل المجلد الكامل.

## طريقة الرفع إلى GitHub

افتح ملف:

`math-apps-grade6-unit7-teacher-kit-pdf-viewer_upload-only.zip`

ثم ارفع محتوياته إلى جذر مستودع `math-apps` بحيث تندمج المجلدات التالية مع المجلدات الموجودة:

```text
apps/
assets/
images/
```

المسار الرئيسي للحقيبة بعد النشر:

```text
https://zuhdizahdeh.github.io/math-apps/apps/grade6-unit7-geometry/
```

## سبب عدم فتح PDF أحياناً

غالباً يحدث ذلك عند أحد هذه الأسباب:

1. تم رفع `index.html` فقط دون مجلدات `plans` و `preparations`.
2. تم تغيير أسماء ملفات PDF أو مكانها بعد إنشاء الروابط.
3. تمت المعاينة داخل بيئة لا تسمح بعرض PDF المدمج.
4. بعض الهواتف أو المتصفحات لا تعرض PDF داخل iframe، لذلك أبقينا أزرار فتح في تبويب جديد وتحميل.
