# طريقة تعديل الأسئلة

الملف الذي يقرأه التطبيق هو:

`data/geometry-questions.js`

وهو يحتوي على المتغير:

```javascript
window.GEOMETRY_QUESTION_BANK = { ... };
```

يمكن تعديل نص السؤال، الخيارات، الإجابة، التلميح، والتغذية الراجعة من هذا الملف فقط دون تعديل `index.html` أو `style.css` أو `script.js`.

## إضافة سؤال جديد

أضف كائن سؤال جديد داخل مصفوفة `questions` الخاصة بالدرس المناسب. مثال لسؤال عددي:

```javascript
{
  "id": "P-006",
  "type": "number",
  "level": 6,
  "difficulty": "medium",
  "prompt": "متوازي أضلاع قاعدته 10 سم وارتفاعه 4 سم. احسب مساحته.",
  "answer": 40,
  "unit": "سم²",
  "tolerance": 0.01,
  "formula": "مساحة متوازي الأضلاع = القاعدة × الارتفاع",
  "visual": { "type": "parallelogram", "base": "10 سم", "height": "4 سم" },
  "misconception": "الخلط بين القاعدة والارتفاع",
  "feedback": {
    "correct": "صحيح؛ 10 × 4 = 40 سم².",
    "wrong": "استخدم القاعدة والارتفاع فقط.",
    "hint": "القانون: المساحة = القاعدة × الارتفاع."
  }
}
```

## أنواع الأسئلة المدعومة

- `choice`: اختيار من متعدد.
- `number`: إجابة عددية.
- `matching`: مطابقة تعريفات.
- `slider`: منزلق مناسب لمهمة الفرجار.
- `open`: مهمة أدائية مفتوحة.

## تنبيه مهم

احرص على:

- عدم تكرار قيمة `id` بين الأسئلة.
- وضع فاصلة بين الأسئلة داخل المصفوفة.
- إبقاء علامات الاقتباس حول النصوص.
- تعديل `geometry-questions.js` إذا أردت أن ينعكس التعديل في التطبيق مباشرة.
