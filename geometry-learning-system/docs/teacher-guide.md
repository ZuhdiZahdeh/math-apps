# دليل المعلم – رحلة مهندس الهندسة

## الفلسفة التعليمية

يعتمد التطبيق على دمج الألعاب التفاعلية ضمن مسار تعلّم واضح:

1. هدف تعليمي.
2. تمهيد أو فكرة كبرى.
3. نشاط تفاعلي.
4. تغذية راجعة تشخيصية.
5. بطاقة خروج.
6. تقرير تقدم.

هذا يجعل التطبيق مناسبًا للتقويم التكويني وملف الإنجاز.

## ترتيب الدروس

1. الارتفاع والبعد العمودي.
2. مساحة المستطيل والمربع والمثلث.
3. مساحة متوازي الأضلاع.
4. مساحة شبه المنحرف.
5. عناصر الدائرة ومختبر الفرجار.
6. محيط الدائرة ومساحتها.
7. تحدي مهندس الهندسة الختامي.

## كيفية إضافة سؤال جديد

داخل `data/geometry-questions.js` ابحث عن الدرس المناسب داخل مصفوفة `lessons` ثم أضف كائن سؤال جديد داخل `questions`.

مثال مبسط لسؤال عددي:

```js
{
  "id": "P-06",
  "type": "number",
  "difficulty": "medium",
  "prompt": "متوازي أضلاع قاعدته 10 سم وارتفاعه 4 سم. احسب مساحته.",
  "answer": 40,
  "unit": "سم²",
  "tolerance": 0.01,
  "formula": "المساحة = القاعدة × الارتفاع",
  "visual": { "type": "parallelogram", "base": 10, "height": 4, "unit": "سم" },
  "feedback": {
    "correct": "صحيح. 10 × 4 = 40 سم².",
    "wrong": "تأكد من استخدام الارتفاع العمودي.",
    "hint": "القانون: القاعدة × الارتفاع."
  },
  "misconception": "استخدام الضلع المائل بدل الارتفاع"
}
```

## أنواع الأسئلة المدعومة

- `choice`: اختيار من متعدد.
- `number`: إجابة عددية.
- `matching`: مطابقة المفاهيم والتعريفات.
- `slider`: منزلق تفاعلي مثل فتحة الفرجار.
- `open`: مهمة أدائية أو إجابة مفتوحة.

## توصية للاستخدام داخل الحصة

استخدمي التطبيق بعد التمهيد القصير، وليس بدل الشرح الكامل. يمكن تشغيله فرديًا أو ضمن مجموعات، ثم توظيف تقرير الطالب وبطاقة الخروج لتحديد الطلاب الذين يحتاجون دعمًا علاجيًا.
