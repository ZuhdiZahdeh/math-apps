# رحلة مهندس الهندسة

تطبيق تعلم تفاعلي موحّد لوحدة الهندسة في الصف السادس الأساسي.

## طريقة التشغيل

افتح الملف:

`index.html`

مباشرة من المتصفح. لا يحتاج التطبيق إلى خادم محلي؛ لأن ملف الأسئلة محمّل بصيغة JavaScript منفصلة بدلاً من `fetch` لملف JSON.

## بنية التطبيق

```text
geometry-learning-system-final/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── data/
│   ├── geometry-questions.js
│   └── geometry-questions.json
└── docs/
    ├── teacher-guide.md
    └── edit-questions.md
```

## الملفات الأساسية

- `data/geometry-questions.js`: ملف الأسئلة والأهداف والتغذية الراجعة الذي يقرأه التطبيق فعلياً.
- `data/geometry-questions.json`: نسخة مرجعية منظمة من بنك الأسئلة.
- `css/style.css`: ملف التنسيقات الموحد.
- `js/script.js`: محرك التطبيق الموحد: التنقل، التصحيح، النقاط، التغذية الراجعة، وحفظ التقدم.

## المزايا

- صفحة رئيسية موحدة.
- خريطة تعلم لكل دروس وحدة الهندسة.
- أهداف وتمهيد وتوجيهات معلم لكل درس.
- أسئلة اختيار، أسئلة عددية، مطابقة، منزلق فرجار، ومهمة أدائية.
- تغذية راجعة تشخيصية حسب الخطأ.
- نظام نقاط موحد حسب عدد المحاولات.
- حفظ التقدم محلياً في المتصفح باستخدام `localStorage`.
- تقرير طالب ولوحة معلم قابلة للطباعة والتصدير.
