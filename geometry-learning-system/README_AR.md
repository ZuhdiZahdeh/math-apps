# رحلة مهندس الهندسة – تطبيق تعليمي موحّد لوحدة الهندسة

هذا التطبيق يدمج الألعاب التفاعلية السابقة في نظام تعليمي واحد للصف السادس الأساسي، مع المحافظة على فصل المحتوى عن البرمجة والتنسيق.

## طريقة التشغيل

1. فك ضغط الملف.
2. افتح الملف `index.html` مباشرة في المتصفح.
3. لا يحتاج التطبيق إلى خادم محلي؛ لأنه يستخدم ملف أسئلة بصيغة JavaScript بدل تحميل JSON عبر `fetch`.

## بنية الملفات

```text
geometry-learning-system-final/
  index.html
  data/
    geometry-questions.js      ← ملف الأسئلة والأهداف والتغذية الراجعة المعتمد للتشغيل
    geometry-questions.json    ← نسخة مرجعية اختيارية من البيانات
  css/
    style.css                  ← ملف التنسيق الموحد
  js/
    script.js                  ← ملف السكريبت الموحد
  docs/
    teacher-guide.md           ← دليل المعلم والتعديلات
```

## لماذا ملف الأسئلة JS وليس JSON فقط؟

عند فتح `index.html` مباشرة من الجهاز عبر `file://`، قد تمنع بعض المتصفحات قراءة ملفات JSON باستخدام `fetch`. لذلك تم اعتماد:

```text
data/geometry-questions.js
```

ويحتوي على:

```js
window.GEOMETRY_QUESTION_BANK = { ... };
```

بهذا يبقى المحتوى منفصلًا عن التطبيق، وفي الوقت نفسه يعمل مباشرة من المتصفح دون GitHub Pages أو خادم محلي.

## تعديل سؤال أو إضافة سؤال

افتح الملف:

```text
data/geometry-questions.js
```

ثم عدّل نص السؤال أو الإجابة أو التغذية الراجعة داخل الدرس المناسب. حافظ على:

- علامات الاقتباس.
- الفواصل بين العناصر.
- اسم المتغير `window.GEOMETRY_QUESTION_BANK`.
- الفاصلة المنقوطة الأخيرة `;`.

## المزايا المدمجة

- صفحة رئيسية موحدة.
- خريطة تعلم للوحدة.
- تفعيل جميع مستويات لعبة الارتفاعات.
- أسئلة حسابية، اختيار من متعدد، مطابقة، منزلق فرجار، ومهام أدائية.
- تغذية راجعة تشخيصية مرتبطة بالأخطاء الشائعة.
- نظام نقاط موحد.
- بطاقة خروج لكل درس.
- تقرير طالب قابل للطباعة والتصدير.
- لوحة معلم تعرض التشخيص وأنواع الأنشطة وسلّم تقدير مختصر.

## ملاحظة مهنية

هذا التطبيق مصمم كمنتج تعليمي للـ portfolio، وليس كألعاب منفصلة. لذلك يظهر كل درس مرتبطًا بالهدف، التمهيد، النشاط، التغذية الراجعة، التقويم، والتوثيق.
