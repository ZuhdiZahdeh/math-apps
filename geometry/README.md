# geometry

موقع موحّد يجمع:
- `plane.html` — حلول الهندسة المستوية
- `space.html` — حلول هندسة الفراغ
- `theorems.html` — مرجع النظريات الهندسية
- `data/theorems-master.json` — المصدر الحقيقي الوحيد للنظريات

## مبدأ العمل
الصفحات الثلاث تعتمد على ملف واحد للنظريات:
`data/theorems-master.json`

أي تعديل على نظرية داخل هذا الملف ينعكس مباشرة على:
- بطاقات النظريات في صفحة المستوية
- بطاقات النظريات في صفحة الفراغ
- صفحة مرجع النظريات

## الملفات الأساسية
- `data/plane-book.json`
- `data/plane-final.json`
- `data/space-solutions.json`
- `data/theorems-master.json`

## ملاحظة حول الصور
النسخة المرفقة لا تتضمن مجلد الصور الأصلي `images/`.
لإظهار الرسومات والصور المرتبطة بالأسئلة والنظريات، ضع مجلد `images/` في جذر المشروع بنفس الأسماء والمسارات المتوقعة.
