نسخة المشروع النهائية المحسّنة

ما تم عمله:
- تم وضع ملفات البيانات المحسّنة داخل data/ بالأسماء الأصلية التي يتوقعها المشروع.
- تم تحسين sidebar ليصبح:
  - قابلًا للطي على Desktop
  - Overlay على Mobile
  - منظّمًا عبر Accordion
- تم دعم حفظ حالة طي الشريط وبعض أقسامه.
- تم تحسين عرض القوائم لتقرأ حقول grouping من البيانات الجديدة مباشرة.
- تمت إضافة اختصارات:
  - / للانتقال إلى البحث
  - Ctrl+B أو Cmd+B لطي/إظهار الشريط على الشاشات الكبيرة

مهم:
- الصور الأصلية لم تكن مرفقة في هذه الجلسة، لذلك أُنشئت مجلدات images/ فارغة فقط.
- إذا كانت لديك الصور الفعلية، انسخها إلى نفس المسارات المتوقعة داخل images/.
- لا حاجة لإعادة تسمية ملفات js أو json داخل هذه الحزمة؛ هي جاهزة بالأسماء الأصلية.
